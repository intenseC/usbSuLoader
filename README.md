UsbSuloader — Self-Recovering USB Cellular Modem

Turn a rooted Android phone into a more resilient USB cellular modem for a router or PC.

UsbSuloader automatically re-enables USB RNDIS tethering when the USB connection is re-established, helping the phone recover its network-facing role without manual intervention.

The idea is simple: connect the phone to a USB host and let it restore the USB networking configuration when needed, rather than having to babysit tethering after reconnects.

Originally developed as part of a cellular backup-WAN setup using Android and OpenWrt.
